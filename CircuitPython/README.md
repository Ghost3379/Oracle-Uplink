# Oracle Uplink (CircuitPython)

This is the Python implementation of the Oracle Uplink bridge library.

## Installation

1. Make sure your board is running **CircuitPython**.
2. Download the official [CircuitPython Library Bundle](https://circuitpython.org/libraries).
3. Connect your board via USB. It will mount as a drive called `CIRCUITPY`.
4. Copy the entire `oracle_uplink` folder from this directory into the `lib/` folder on your `CIRCUITPY` drive.

## Dependencies

Depending on which transport method you want to use, you must copy the following folders from the Library Bundle into your `lib/` folder:

* **BLE**: Requires the `adafruit_ble` folder.
* **USB**: Requires no external dependencies!

See the `examples/` folder for code snippets to get started.
