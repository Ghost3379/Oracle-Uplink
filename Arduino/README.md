# Oracle Uplink (Arduino C++)

This is the C++ implementation of the Oracle Uplink bridge library, designed primarily for the ESP32 family of microcontrollers.

## Installation

1. Download this entire repository as a ZIP file (or clone it).
2. Open the **Arduino IDE**.
3. Go to **Sketch** -> **Include Library** -> **Add .ZIP Library...**
4. Select the `Arduino/OracleUplink` folder (you may need to zip it first depending on your IDE version, or just copy the `OracleUplink` folder directly into your `Documents/Arduino/libraries/` directory).

## Dependencies

You must install these libraries via the Arduino IDE Library Manager (`Ctrl+Shift+I`):

* **NimBLE-Arduino** by h2zero (Used for memory-efficient Bluetooth).
* **ArduinoJson** by Benoit Blanchon (Version 7.x).
